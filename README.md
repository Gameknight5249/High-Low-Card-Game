# 🃏 High/Low Card Game

A command-line High/Low card game built with Python. The player is shown a randomly generated card and predicts whether the next card will be higher or lower.

I created this project to practice Python fundamentals, build my problem-solving skills, and gain experience turning a set of game rules into working program logic.

## 🎮 How the Game Works

The game begins by randomly generating a **baseline card**. After seeing this card, the player chooses whether they think the next card will be **higher** or **lower**.

The program then generates a second card and compares it with the baseline card to determine whether the player won, lost, or tied.

For this version of the game, suits are ranked from lowest to highest:

**Clubs < Diamonds < Hearts < Spades**

Card values are ranked from:

**Ace < 2 < 3 < ... < 10 < Jack < Queen < King**

The suit is compared first. If both cards have the same suit, their card values are compared instead.

## 🧠 How the Card Comparison Works

One of the main problems I needed to solve was figuring out how to make Python understand that one suit or card value should rank higher than another.

Instead of manually programming every possible card matchup, I stored the suits and card values in lists ordered from lowest to highest.

For example:

```python
suit = ["Clubs", "Diamonds", "Hearts", "Spades"]
```

The program can find the position of a card's suit within the list using `.index()` and compare that position with the other card.

This allows the game's ranking rules to be represented through the data itself instead of requiring a separate conditional statement for every possible matchup.

If both cards have the same suit, the program uses the same approach with the card-value list to determine which card is higher.

## ▶️ Running the Game

### Requirements

Make sure Python 3 is installed on your computer.

### Run

Clone or download this repository, navigate to the project's directory, and run:

```bash
python high-low.py
```

Depending on your system, you may need to use:

```bash
python3 high-low.py
```

The game will display the baseline card and ask:

```text
High or Low?
```

Enter `high` or `low` to make your prediction.
